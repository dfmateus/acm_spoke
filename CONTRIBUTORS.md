# Contributors

## Author and maintainer

**Diego Felipe Mateus** ([GitHub](https://github.com/dfmateus) | [LinkedIn](https://www.linkedin.com/in/dfmateus/)) created this collection to solve the spoke cluster access problem in RHACM environments. The collection resolves temporary ManagedServiceAccount tokens from the ACM Hub, eliminating static per-cluster credentials across OpenShift, ARO, ROSA, AKS, EKS, GKE, IKS, and vanilla Kubernetes.

## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and guidelines, then open an issue or pull request at [github.com/dfmateus/acm_spoke](https://github.com/dfmateus/acm_spoke/issues).
